# Third-party rights and source-material boundary

This repository is a reproducibility package for a reanalysis of public human
thymus datasets. The dual license in this repository does **not** relicense
third-party source material.

## Public source datasets

The primary source datasets are:

- GEO GSE147520 - human thymic stromal single-cell transcriptomics.
- GEO GSE207206 - pediatric thymus CITE-seq and Visium spatial transcriptomics.

The underlying source data remain subject to the terms of the originating
repositories, source studies, consent/ethics frameworks, and any applicable
third-party rights.

## Publications and source-study material

Text, figures, tables, supplementary material, and other content originating
from source publications are not licensed by this repository unless the author
of this repository independently holds the relevant rights.

## Software dependencies

Third-party software packages and dependencies remain under their own licenses.
The MIT grant in this repository applies only to original software authored for
this project.

figures/visualizations under CC BY 4.0 only to the extent that the author holds
copyright or similar rights in those outputs. The licensing statement does not
change rights in the underlying third-party datasets from which analyses were
